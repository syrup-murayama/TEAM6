# AI二度寝裁判所 — 画面設計・screen flow

Submitted by: unknown (name to be confirmed)

## 1. 全体フロー

起点はアラームの発火です。そこから「開廷 → 入力 → 審理 → 判決 → 執行」という法廷の型をなぞらせ、最後だけ「欠勤」という人間の意志確認ゲートに分岐させます。

1. アラーム発火画面（起点）
2. 二度寝申立書（入力画面）：眠さレベル／今日の予定／昨夜の就寝時刻
3. 開廷中（AI審理中の待機演出）
4. 判決画面：二度寝◯分許可 or 即時棄却、判決理由文つき
   - 5a. 執行画面（許可時）：アラーム・予定が自動で後ろ倒しされる様子を見せる
   - 5b. 起床促し画面（却下時）：カウントダウンでの起床誘導
5. 人間ゲート：「本日は起き上がれない（欠勤）」への長押し承認画面

## 2. 画面ごとの設計

### 画面1｜アラーム発火

- 背景：朝焼けグラデーション（オレンジ→パープル）。ビビッドで眠気を吹き飛ばす配色
- 中心：寝ぼけ顔の目覚まし時計を擬人化したマスコット（AI裁判官の下位人格、というポジション）
- コピー：「起きた…？　それとも、まだ…？」
- CTA：大きな丸ボタン「申し立てる」（アラームを止める操作＝裁判所への出頭、という比喩でボタンを兼ねる）

### 画面2｜二度寝申立書（入力画面）

法廷の書式をポップに崩したフォーム画面。

- ヘッダー：「二度寝申立書」。木槌アイコンだが彩度高めのカラーで法廷感とポップ感を両立
- 質問1：眠さレベル（1〜10のスライダー。数値ではなく表情の変化で段階を見せる）
- 質問2：今日の予定（カレンダー連携があれば自動表示、最初の予定と開始時刻を大きく強調）
- 質問3：昨夜の就寝時刻（タイムピッカー）
- CTA：「証拠を提出し、判決を仰ぐ」

### 画面3｜開廷中（審理演出）

- AI裁判官キャラが木槌をコンコン鳴らすコミカルなアニメーション
- コピー：「審理中…しばし待たれよ」
- 進捗表現：法廷らしい砂時計モチーフのプログレス（2〜3秒程度でテンポよく終える）

### 画面4｜判決画面（最大の見せ場）

- 「判決」の大きなハンコがドンと押される演出
- 証書／巻物調のカードに、ビビッドな縁取りと影
- 判決理由文のサンプル
  - 許可：「主文。申立人の二度寝を、9分間に限り認める。ただし9分経過後の即時起床を条件とする。」
  - 棄却：「主文。申立人の二度寝の訴えを棄却する。10時の会議を鑑み、直ちに起床すべし。」
- 色分け：許可はグリーン系、棄却はレッド系のアクセントで直感的に判別できるようにする
- CTA：許可時「執行する（9分後にアラーム再設定）」／棄却時「起床する（タイマー開始）」

### 画面5a｜執行（許可時）

- 新しいアラーム時刻と、後ろ倒しされた予定一覧を、時刻がスライドして動くアニメーションで見せる
- 念押しコピー：「9分後、必ず起こしますからね」

### 画面5b｜起床促し（棄却時）

- 中央に大きなカウントダウンタイマー
- コピー：「判決は判決。さあ、布団から出よ。」

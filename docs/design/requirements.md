# AI二度寝裁判所 — 要件定義

## コンセプト

「くだらない決断ほど、AIに全部任せてしまう未来」を1分で伝えるジョークアプリ。
朝、二度寝していいかどうかを人間同士で悩む代わりに、AI裁判官に判決を仰ぐ。
ただし「会社を休む」という人生に影響する決断だけは、人間の明示的な承認（3秒長押し）が必要——
「小さな決断はAIに、大きな決断は人間に」という思想を1つのアプリ体験で示す。

## コア体験フロー（v2: 音声ファースト、2026-09-13更新）

「寝起きで画面操作したくない」を体現するため、**最初の1タップ（アラームを止める操作）以外はすべて音声で完結**させる。健康データ（Apple Watch）と予定（カレンダー）は「すでに連携済み」という前提でサーバー側にモックデータを持たせ、実連携はしない（デモとして"繋がっているように見せる"）。

1. **アラーム画面**：画面をタップ（＝アラームを止める、ブラウザの自動再生制限を満たす唯一の操作）
2. **AIが先に話しかける**：ElevenLabsの音声で「起きた…？　それとも、まだ…？」と自動再生
3. **AIが自動で聞く**：発話終了後、自動でマイクがオンになりユーザーの発話（言い訳・気分など）をWeb Speech APIで認識。ユーザーは何も操作しない
4. **審理**：認識したテキスト＋Apple Watch/カレンダーのモック連携データ（就寝時刻・睡眠の質・今日最初の予定）をAI裁判官に送り、判決を生成
5. **判決の音声宣告**：判決文をAIが自動で声で読み上げる（ボタン操作なし）
6. **執行画面へ自動遷移**：許可時はアラーム・予定を自動で後ろ倒しして見せる／棄却時はカウントダウンで起床を促す
7. **人間ゲート**：「今日は会社を休む」だけは3秒長押しでの本人承認が必須（唯一の手動操作。AIが単独で確定しない、という核心をここで見せる）

### API仕様（v2）

- `GET /api/context` — Apple Watch/カレンダーのモック連携データ＋現在時刻を返す（画面上部の「⌚連携済み」「📅連携済み」バッジ表示用）
- `POST /api/judge` — `{ transcript: string }` を受け取り、サーバー側のモック連携データと合成してLLMに送り、判決JSON `{verdict, minutes, reason, verdictText}` を返す
- `POST /api/speak` — `{ text: string }` を受け取り、ElevenLabsでMP3音声を返す（既存のまま）

## 機能要件

| 機能 | 内容 | 実現方法 |
|---|---|---|
| 音声入力 | ユーザーの発話をテキスト化 | ブラウザ標準 Web Speech API（`SpeechRecognition`、Chrome想定） |
| AI判決生成 | 眠さ・予定・就寝時刻から判決文＋許可分数を生成 | Claude API（`/api/judge`） |
| 音声出力 | 判決文を音声化して再生 | ElevenLabs API（`/api/speak`） |
| スケジュール再調整 | 許可時にアラーム・予定を自動で後ろ倒し表示 | フロントのみで計算・アニメーション表示（実データ連携なし、デモ用のシミュレーション） |
| 人間承認ゲート | 「欠勤」だけは3秒長押しで確定 | フロントのUIコンポーネント（AIの判定結果に関わらず必ず人間操作を要求） |

## 非機能要件・スコープ外

- カレンダー連携やApple Watch実連携は行わない（デモではモック/手入力）
- 音声入力はChromeでの動作を前提とし、他ブラウザのフォールバック対応はしない
- 自動テスト整備は本ハッカソンのスコープ外（デモが動くことを優先）
- APIキー（Anthropic, ElevenLabs）は環境変数管理、リポジトリはPublicなので絶対にコミットしない

## 技術スタック

- バックエンド: Node.js + Express（`/api/judge`, `/api/speak` の2エンドポイントのみ）
- フロントエンド: 素のHTML/CSS/JS（ビルドステップなし）
- 外部API: Claude（判決生成）, ElevenLabs（音声合成）
- 音声入力: ブラウザ標準 Web Speech API

## リスクと縮退方針

- 音声入力がデモ環境で不安定な場合 → 眠さスライダー入力にフォールバック（音声出力・判決演出は維持）
- 時間が足りない場合 → 削る優先順位は「音声入力 → スケジュール再調整アニメーション」の順（AIが声で判決を言い渡す体験は最後まで残す）

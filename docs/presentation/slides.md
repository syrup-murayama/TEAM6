- ビジュアル：朝焼けグラデーション（オレンジ→パープル）＋寝ぼけ顔マスコット `[SCREENSHOT: 画面1 アラーム発火]`

## スライド2｜共感導入（課題）

**見出し**：私たちは毎朝、同じ裁判を開いている

- 箇条書き（`docs/episodes/asuka.md` より）：
  - 「あと9分だけなら大丈夫」
  - 「いや、絶対に遅刻する」
  - 「昨日は頑張ったから寝てもいい」
  - 「それを昨日も言っていた」
- 一言：「裁判官も検察官も被告人も、全部自分。判決はだいたい感情で決まる。」
- 発表メモ：説明不要の「あるある」で笑いを取り、会場を自分ごと化させる。ここは1文で素早く通過。

## スライド3｜コンセプト（コアフロー）

**見出し**：二度寝を、AI裁判官に委ねる

- フロー図（横並び矢印）：
  申立（音声）→ 審理（AI裁判官）→ 判決（許可 or 棄却）→ 執行（アラーム・予定を自動調整）
- 補足：判決理由つき／音声で宣告（ElevenLabs）
- 発表メモ：「便利な目覚まし時計に見えますが、本当に見せたいのはこの先です」で次スライドへの引きを作る。

## スライド4｜デモ

**見出し**：（このスライドは口頭デモのつなぎ。テキストは最小限）

- 実演順（`pitch.md` §2 参照）：
  1. アラーム発火 → 申し立てる
  2. 音声で「まだ眠い」→ 二度寝申立書に反映
  3. 開廷中の演出（コミカル・テンポよく）
  4. **判決＋音声宣告**（最大の見せ場①）：「9分間の二度寝を認める」
  5. 執行画面：アラーム・予定が後ろ倒しされるアニメーション
  6. 別パターン：眠さ10/10 → 棄却（レッド）で対比を見せる
  7. **欠勤の人間ゲート、3秒長押し**（最大の見せ場②）

- 発表メモ：時間が押していたら4・7だけは死守（判決音声＋長押しゲート）。締めの一言：「二度寝の9分はAIが決めました。でも、休むかどうかは、今、僕の指がここで決めました。」

## スライド5｜核心の思想

**見出し**：小さな決断はAIに。大きな決断は人間に。

- 対比表：

  | 決断 | 誰が決めるか | なぜ |
  |---|---|---|
  | あと9分寝る | AI（自動） | 可逆・影響は自分の朝だけ |
  | 会社を休む | 人間（3秒長押しで明示的承認） | 不可逆・収入や信用に影響 |

- `[SCREENSHOT: 欠勤承認画面の長押しボタン]`
- 発表メモ：ここがQ&A「なぜAIに人生の決断を任せるのか」への予防線にもなる。線引きの基準は「取り消せるか／他者に影響するか」と口頭で補足。

## スライド6｜10年後のビジョン

**見出し**：10年後、朝の決断はAIに任せる。

- 引用（`docs/episodes/asuka.md` より）：
  > 今のAIは、人間に答えを返す。
  > 10年後のAIは、人間の状況を理解し、小さな決断を引き受け、必要なところまで行動する。
  > でも、すべてをAIに任せるわけではない。
- 締め：「判決を聞いて、安心してもう一度目を閉じる。それが10年後の当たり前になる。」
- 発表メモ：情緒に訴えるスライドなので、ここはゆっくり話す。

## スライド7｜技術構成（Q&A備え／バックアップ）

**見出し**：使った技術（1時間で動かした構成）

- バックエンド：Node.js + Express（`/api/judge`, `/api/speak` の2エンドポイントのみ）
- AI判決：Claude API
- 音声出力：ElevenLabs API（TTS）
- 音声入力：ブラウザ標準 Web Speech API（Chrome想定）
- フロントエンド：素のHTML/CSS/JS（ビルドステップなし）
- スコープ外：カレンダー/Apple Watch実連携、自動テスト（デモ優先のため）
- 発表メモ：時間が余ったら見せる。時間がなければ省略し、Q&Aで聞かれたら口頭で回答（`pitch.md` §3 Q3, Q4 参照）。

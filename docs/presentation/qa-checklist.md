# 本番デモ前 QA チェックリスト

デモ機（発表に使う Chrome）で、発表の直前に上から順に確認する。自動テストはハッカソン範囲外なので、このリストが受け入れの実務チェックになる。観点は `docs/agent/review-checklist.md` の positive / negative / transition / recovery に合わせている。

正とする仕様は [requirements.md](../design/requirements.md) の「コア体験フロー（v2: 音声ファースト）」と `public/index.html`（`#screen-alarm` → `#screen-listening` → 審理 → 判決 → 執行）。申立書フォーム・眠さスライダーは廃止。`#fallback-form` は音声非対応ブラウザ用で、通常は `hidden`。

## 環境・シークレット

- [ ] `.env` がある（`example.env` をコピーした実ファイル。リポジトリにコミットしていない）
- [ ] `JUDGE_PROVIDER` が `xai` / `openai` / `anthropic` のいずれかで、**選んだ側の API キーだけ**が入っている
  - `xai` → `XAI_API_KEY`
  - `openai` → `OPENAI_API_KEY`
  - `anthropic` → `ANTHROPIC_API_KEY`
- [ ] `ELEVENLABS_API_KEY` が入っている（挨拶音声・判決読み上げの両方に必要）
- [ ] 使わないプロバイダのキーが空でも、選んだプロバイダで判決が返る
- [ ] `pnpm start` で `http://localhost:$PORT`（既定 3000）が開き、コンソールに起動ログが出る
- [ ] `GET /api/context` が 200 で、Apple Watch / カレンダーのモック（就寝時刻・睡眠の質・今日最初の予定など）と現在時刻を返す
- [ ] 起動ログや画面に API キーが印字されていない

## デモ機・ブラウザ（positive）

- [ ] 発表ブラウザは **Google Chrome**（Web Speech API は Chrome 想定。他ブラウザのフォールバックはスコープ外）
- [ ] アドレスは `http://localhost:3000` またはトンネルの `https://` URL（マイクはセキュアコンテキストが必要）
- [ ] Chrome のマイク権限がこのオリジンで「許可」になっている（初回はプロンプトが出る。拒否済みならサイト設定から直す）
- [ ] タブがミュートになっていない。OS / Chrome の音量が聞こえる大きさ
- [ ] **最初の1タップ**（「アラームを止める」）のあと、挨拶音声が自動再生される（このタップが autoplay 制限を外す唯一の操作）
- [ ] 判決音声もボタンなしで自動再生される。もしブロックされたら、その場でタブ音量 / サイト設定を直してやり直す（v2 に判決 CTA はない）
- [ ] 画面がスマホ幅でもアラーム停止と欠勤の長押しが届く

## 画面遷移（transition）— v2 音声ファースト

通しで、戻らずに次へ進むこと。Chrome では申立書もスライダーも出さない。

- [ ] **アラーム**「アラームが鳴っています」→「アラームを止める」が最初で最後の通常タップ
- [ ] タップ後 **聴取**（`#screen-listening`）へ。AI が「起きた…？　それとも、まだ…？」と先に話す
- [ ] 挨拶のあと、追加タップなしでマイクがオンになり「聞いています…」になる
- [ ] ユーザーが話すと `#listen-transcript` に認識結果が出る（操作はしない）
- [ ] 発話終了後、自動で **開廷中**「審理中…しばし待たれよ」
- [ ] 開廷中のあと **判決** に進み、主文が表示され、自動で読み上げられる（執行ボタンは無い）
- [ ] 読み上げ後、**執行画面へ自動遷移**（許可 / 棄却で文言が分岐する）
- [ ] 執行画面に欠勤ゲート「本日は休む（3秒長押しで承認）」がある（ここが唯一の手動ゲート）
- [ ] 「もう一度（デモリセット）」でアラーム画面に戻り、欠勤ボタンが未承認状態に戻る
- [ ] Chrome の正常系では `#fallback-form` が隠れたまま（申立書が出ない）

## 許可ルート（positive）

固定モックは就寝 01:18・睡眠 5.7h・質低め・定例ミーティング 09:30。発話で「まだ眠い」「会議まで余裕」など許可寄りにしてよい。

- [ ] 判決カードが許可（グリーン系）になる
- [ ] 主文に許可分数が含まれる（例: 「◯分間に限り認める」）
- [ ] 判決が声で読み上げられ、ボタン操作なしで執行画面へ進む
- [ ] 執行画面に新しいアラーム時刻と、予定が後ろ倒しされた表示が出る
- [ ] 許可ルートを **アラーム停止から執行まで 1 回**、手入力なしで通した

## 棄却ルート（positive）

同じモックのまま、発話で「すぐ会議」「起きられない」など棄却寄りにしてよい。

- [ ] 判決カードが棄却（レッド系）になる
- [ ] 主文が即時起床を命じる
- [ ] 棄却側も音声宣告が自動再生され、執行（起床促し）へ自動遷移する
- [ ] 起床促しのコピーが出る（設計: 「判決は判決。さあ、布団から出よ。」）
- [ ] 棄却ルートを **アラーム停止から執行まで 1 回**、手入力なしで通した

## 音声入力（positive / negative）

- [ ] アラーム停止の **あと** はマイク開始をタップしなくてよい
- [ ] 認識中に画面を触らなくても、発話が審理に送られる
- [ ] マイク拒否・認識エラーでもアプリが白画面にならず、デモを止められる（Chrome では隠れたフォールバックを出さずにやり直すのが本線）
- [ ] 音声非対応ブラウザだけで `#fallback-form` が見える。Chrome デモでは出さない
- [ ] フォールバックを出す場合も、眠さスライダーや申立書フォームは使わない（廃止済み）

## Negative（壊しても安全か）

- [ ] 無言 / 聞き取れない（空の transcript）でも `/api/judge` が落ちず判決が返る（サーバは `(聞き取れず)` で合成する）
- [ ] 就寝時刻・予定時刻を画面から入力する UI が無い（それらはサーバーモック。手で書き換えない）
- [ ] `JUDGE_PROVIDER` とキーが食い違う（例: `openai` なのに `OPENAI_API_KEY` が空）と判決 API は失敗するが、フロントは落ちない
- [ ] ElevenLabs キーが無い / 失敗しても判決テキストは出る（無音でも画面の主文で宣告が読める）
- [ ] サーバ停止中でも白画面にならない
- [ ] `.env` をコミット対象にしていない（`git status` で `.env` が出ない）

## Recovery（失敗からの復帰）

- [ ] `/api/judge` 失敗時も体験が止まりきらず、リセットまたは棄却相当で最初に戻れる
- [ ] 欠勤を承認したあと「もう一度（デモリセット）」で、欠勤ボタンが再び長押し待ちになる（disabled が残らない）
- [ ] 挨拶または判決の autoplay が一度ブロックされたら、ページを再読み込みして **アラーム停止から** やり直すと再生できる
- [ ] トンネルを切り直したら、**新しい URL** を共有し直し、古い URL を開かない

## 人間ゲート（safety — 欠勤は AI が単独確定しない）

v2 では欠勤の 3 秒長押しが、アラーム停止以外の唯一の手動操作。クリックや短いタップでは通さない。

- [ ] 欠勤ボタンの短クリック（3秒未満）では「承認済み」にならない。表示が「長押し中…」から元の「本日は休む（3秒長押しで承認）」に戻る
- [ ] 押して 1〜2 秒で指/マウスを離すと未承認のまま
- [ ] ボタンの外へマウスを出して離しても未承認のまま（誤爆防止）
- [ ] 約 3 秒以上押し続けると「本日は休みます（承認済み）」になり、ボタンが押せなくなる
- [ ] 判決が許可でも棄却でも、欠勤は **同じ長押し** が必要（AI の許可分数では欠勤が確定しない）
- [ ] タッチ（実機 or デベロッパーツールのモバイル）でも 3 秒ゲートが同じ挙動

## 公開トンネル

- [ ] 端末 A: `pnpm start` が生きている
- [ ] 端末 B: `pnpm tunnel`（`cloudflared tunnel --url http://localhost:3000`）
- [ ] 表示された `https://*.trycloudflare.com` を別端末/別ブラウザで開ける
- [ ] トンネル経由でも アラーム停止 → 挨拶音声 → 自動聴取 → 判決音声 まで通る（マイクは HTTPS 側で再許可が必要なことがある）
- [ ] 発表スライド / チャットに貼る URL が、今動いているトンネルと一致している

## 発表直前（1周）

- [ ] 許可 1 本・棄却 1 本を、**声だけ**（アラーム停止と欠勤長押し以外タップしない）で通しでやった
- [ ] 欠勤ゲートを「短いクリックでは動かない → 3秒で承認」と見せる手順を一度リハーサルした
- [ ] 縮退手順を口で言える: TTS 失敗 → 画面の主文を読む。マイク失敗 → ページ再読み込みしてアラームからやり直し（スライダーには戻さない）。時間不足でも「AI が先に話し、判決を声で言う」は残す

## 設計との差分（デモで踏まない / 期待しすぎない）

`public/index.html` と requirements v2 を正とする。`public/app.js` の結線は別タスクが実装中のことがある。

- [ ] Apple Watch / カレンダーは **実 API 連携ではない**。サーバーにモックが組み込み済み（`GET /api/context` と `POST /api/judge` が合成する）。手入力で就寝時刻や予定を入れない。デモでは「もう繋がっている」前提で話してよい
- [ ] 申立書・眠さスライダー・判決 CTA は v2 で廃止。残っているのは音声非対応用の隠れたテキスト送信だけ
- [ ] 棄却時の大きなカウントダウン、許可時の時刻スライド演出は画面仕様の見せ方。HTML はタイトルと詳細テキストが本体なので、未実装でも文言で成立させる
- [ ] 欠勤ゲートは独立画面ではなく、執行画面の下部
- [ ] 判決モデルは設計文面の「Claude 固定」ではなく、`JUDGE_PROVIDER` で xAI / OpenAI / Anthropic を切替える
